# BASQARU

Нативная игра на Godot 4.4.1: директор казахстанской компании собирает команду. Интерфейс, анкеты и разговоры — на казахском. Графика — 16 сгенерированных фотосцен (пустой кабинет и 15 кандидатов), без браузера, WebView или 3D-сцены. HUD — дымчатый графит со светло-стальными акцентами.

## Запуск на этом компьютере

```bash
cd /home/yernur/basqaru
./run
```

`run` запускает локальный сервис и нативную Linux-сборку из `build/`, если она есть. Иначе запускает проект в установленном Godot. При закрытии игры сервис завершается. F11 переключает полный экран, Esc закрывает панель или возвращает в меню. Для новых анкет и ответов нужен интернет.

## Игровой цикл

1. Введите название и описание компании.
2. Alem AI / gemma4 создаст 15 разных анкет, характеров, сильных и слабых сторон с учётом бизнеса. Создание обычно занимает около минуты, иногда дольше.
3. Открывайте анкеты, задавайте любые вопросы, сохраняйте заметки. Можно вернуться к любому кандидату.
4. Наберите пять человек. До финального подтверждения состав можно менять.
5. Получите оценку команды и рекомендации вместо надписи «вы выиграли».

Пять направлений: продукт/услуги, клиенты, операции, финансы, рост/маркетинг. Каждый представлен тремя кандидатами. Направления, скрытые параметры и зарплаты перемешиваются при новой игре; внешность, возраст и пол не влияют на оценку.

Оценка: профессиональные навыки 35, надёжность 20, работа в команде 20, охват пяти направлений 15, бюджет 10. Индивидуальные параметры усредняются по пяти членам команды. Каждый охваченный профиль даёт 3 очка. Бюджет — 2 200 000 ₸ в месяц; превышение на 25% обнуляет бюджетную часть. 80+ — сильная команда, 60–79 — есть потенциал, ниже 60 — нужны изменения. Скрытые параметры не отправляются клиенту до финала; модель раскрывает их через примеры из опыта.

Сохранения, диалоги и заметки лежат в `data/`. Указатель последней игры — в Godot `user://progress.cfg`. Новая игра не удаляет прошлые файлы. Действующие ключи и сохранения не включены в ресурсы Godot.

## Устройство проекта

- `game/` — нативный клиент Godot/GDScript, сцены и изображения.
- `service/server.py` — локальный Python-сервис, вызовы Alem AI, генерация и валидация анкет, память диалогов, расчёт результата.
- `.env` — локальная конфигурация API с правами 600, исключена из Git. Не включать в распространение.
- `image-prompts.json` — промпты и происхождение фотосцен (встроенный image_gen).
- `tests/live_check.py` — реальная интеграционная проверка API; требует сеть и расходует токены Alem AI.
- `game/export_presets.cfg` — Linux и Windows export presets.

Сервис слушает только localhost. Лаунчер создаёт случайный локальный токен и свободный порт на каждый запуск. Клиент не содержит ключа Alem AI. Генерация анкет и характеров: `ALEM_MODEL=gemma4`, `ALEM_URL=https://llm.alem.ai/v1/chat/completions`, ключ `ALEM_API_KEY`. Ответы персонажей после генерации: `ALEM_CHAT_MODEL=gpt-oss`, `ALEM_CHAT_URL=https://llm.alem.ai/chat/completions`, отдельный ключ `ALEM_CHAT_API_KEY`. Переменные окружения имеют приоритет над `.env`. Существующие анкеты и сценарии при смене модели диалога сохраняются.

## Экспорт

Требуются официальные export templates Godot 4.4.1.

```bash
godot --headless --path game --export-release Linux ../build/Basqaru.x86_64
godot --headless --path game --export-release Windows ../build/Basqaru.exe
```

В установленном окружении использовать абсолютный путь `/home/yernur/.local/bin/godot`. Пути export-пресетов уже настроены на `../build/`. Для Linux запускайте через `run`: отдельному клиенту нужен работающий сервис. Windows-клиент можно подключить к сервису через `BASQARU_API_URL` и `BASQARU_TOKEN`; Windows-запуск в этой Linux-среде не проверялся.

## Перед выпуском в Steam

Это рабочий локальный прототип, не опубликованная Steam-версия. Клиент уже нативный, но для распространения нужно разместить LLM-сервис на HTTPS-сервере, добавить проверку пользователя/Steam ticket, ограничения запросов и квоты, определить стоимость обслуживания и правила сохранения данных. Приватный ключ провайдера должен остаться на сервере. Не распространять `.env` и `data/`. Локальный Python-сервис предназначен для разработки и не является готовым публичным backend.

Далее нужны тесты на целевых Windows/Linux устройствах, Steamworks-интеграция по необходимости и подготовка страницы/депо. Художественные материалы сгенерированы; DejaVu Fonts используются по лицензии из `game/assets/FONT-LICENSE.txt`.
